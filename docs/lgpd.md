# LGPD — Diretrizes de Proteção de Dados (MVP)

Este documento define os princípios mínimos de proteção de dados
adotados no MVP do Consumidor 360.

---

## Princípios adotados
- Consentimento explícito do usuário
- Minimização de dados coletados
- Uso inicial do fluxo de forma anônima
- Transparência no uso das informações
- Possibilidade de exclusão dos dados

---

## Dados coletados no MVP
- Respostas fornecidas no fluxo de orientação
- Nome (opcional)
- Endereço de e-mail
- Dados básicos de acesso (data e hora)

Não são coletados:
- CPF, RG ou documentos pessoais
- Endereço residencial
- Dados bancários ou financeiros

---

## Uso dos dados
Os dados são utilizados exclusivamente para:
- Exibir orientação ao usuário
- Permitir salvamento do histórico (quando há cadastro)
- Melhorar o funcionamento do serviço

Os dados não são compartilhados com terceiros.

---

## Consentimento
Nenhum dado pessoal é armazenado sem que o usuário manifeste
consentimento explícito, conforme Política de Privacidade.

---

## Exclusão
O usuário pode solicitar a exclusão dos seus dados a qualquer momento,
por meio do canal informado no site.
