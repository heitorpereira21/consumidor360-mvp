# Escopo do MVP — Consumidor 360

## Objetivo principal
Criar uma porta de entrada simples e confiável para o consumidor:
- Entender sua situação
- Receber orientação inicial
- Saber quais próximos passos seguir
- Validar uso, confiança e indicação

---

## Funcionalidades DENTRO do MVP

### 1. Porta de entrada
- Home page com linguagem simples
- Identificação de dores reais do consumidor
- CTA principal para iniciar orientação

---

### 2. Fluxo guiado de orientação
- Escolha do tipo de problema
- Perguntas simples (sim/não ou múltipla escolha)
- Lógica baseada em regras simples
- Resultado com:
  - Explicação leiga
  - O que isso significa
  - Próximos passos sugeridos

---

### 3. Usuário
- Cadastro simples
- Login
- Área básica do usuário
- Histórico de orientações salvas

---

### 4. Programa de Embaixadores (MVP 0.1)
- Cadastro como embaixador
- Link individual de indicação
- Registro básico de indicados
- Painel simples de acompanhamento

---

## FORA DO ESCOPO (neste MVP)
- Serviços jurídicos
- Mediação de conflitos
- Integrações com órgãos públicos (Procon, tribunais, etc.)
- Comissões automáticas
- Multinível
- Token ou criptomoeda
- Wallet
- App mobile
- Automação ou IA avançada

---

## Regra de escopo
Qualquer funcionalidade que não ajude diretamente a validar uso,
confiança ou indicação deve ser considerada fora do MVP.
