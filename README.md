# Consumidor 360 — MVP

O Consumidor 360 é um MVP em desenvolvimento com o objetivo de servir como
porta de entrada simples e confiável para orientação inicial do consumidor.

## Objetivo do MVP
- Ajudar o usuário a entender sua situação
- Oferecer orientação inicial em linguagem leiga
- Indicar próximos passos possíveis
- Validar uso, confiança e indicação

## Fora do escopo (MVP)
- Serviços jurídicos
- Mediação
- Integrações com órgãos públicos
- Comissões automáticas
- Multinível
- Token / criptomoeda
- App mobile

## Princípio central
Este MVP serve para validar uso, confiança e indicação —
não para sustentar o ecossistema final.

Status: MVP em construção (35 dias)
